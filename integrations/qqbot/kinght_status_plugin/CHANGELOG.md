# 更新记录

## 1.4.12

- Move bot requests to `/api/v1/admin/bot/*` and binding redemption to `/api/v1/admin/bot-bindings/redeem`.
- Preserve administrator `x-api-key`, bound-user `Authorization: Bot`, cached sessions, and existing bindings during key rotation.

## 1.4.10

- 抽奖前先验证绑定账号余额；余额为零或负数时仅返回“余额不足”，不提交抽奖请求。
- 余额读取失败、缺失或异常时停止抽奖，不消耗次数；网站端在事务内再次校验余额。

## 1.4.9

- 新增私聊支付宝、微信充值与本人订单查询，展示支付二维码，实际入账后私聊通知。
- 新增抽奖、次数和记录查询，网站后台配置余额奖池。
- 新增管理员单人及全体有效绑定用户次数发放，批量任务按网站账号去重并支持恢复与进度查询。
- 移除纯英文命令别名及帮助中的英文别名，过滤旧配置中的纯英文触发词；保留 `Key用量`、`首Token` 等原有名称。
- 写操作使用原始消息编号生成幂等标识，超时后恢复原请求，避免重复下单、抽奖和发放。

## 1.4.8

- 本周签到满 7 天才双倍：周一至周日每天都签到，周日领取双倍。
- 签到成功和重复签到新增本月签到、本周签到和真实连续签到天数；本月分母读取网站返回的当月天数，本周分母为 7 天。
- 读取 `month_checked_days`、`month_total_days`、`week_checked_days`、`consecutive_days`；缺失统计显示“暂无数据”，真实零值正常展示，不使用奖励周期 `streak_day` 代替连续签到天数。

## 1.4.7

- 签到门槛不足时按网站返回的 `usage_requirement` 区分每日消费金额和 Token 用量，分别展示 `today_amount / required_amount`（美元，最多 8 位小数）或 `today_tokens / required_tokens`。
- 兼容旧版 Token 门槛响应及错误 `metadata`；门槛由网站配置和判断，奖励仍为余额，成功与重复签到继续显示奖励金额和连续签到天数。

## 1.4.6

- 签到命令新增自定义触发词配置，可在触发词设置中修改；绑定、个人信息、用量、余额预警和状态命令均支持配置自定义触发词。

## 1.4.5

- 新增仅限私聊的 `/个人信息` 和 `/personal_info`，展示绑定网站账号的昵称、用户 ID、余额、总并发、当前并发和近 60 秒 RPM。
- 新增个人信息触发词配置，并在绑定帮助中列出命令；群聊调用时艾特发送者并提示私聊，不请求个人数据。
- 个人信息读取 `GET /api/v1/bot/personal-info`；接口由网站侧提供，本次只更新机器人插件。
- 缺失或为 `null` 的数值项直接省略，真实零值正常展示；总并发小于等于零显示“不限制”。

## 1.4.4

- 账号、签到、余额预警和诊断回复中的状态统一显示为中文；未知英文状态显示为“未知状态”，内部判断仍使用站点原始状态值。
- 配置页插件分组、账号凭据说明和配置版本说明统一为中文。

## 1.4.3

- 签到异常回复补充机器可识别状态，覆盖未绑定、重复签到、绑定失效、未授权、限流和服务异常；显式 `status` 优先于旧版布尔字段。
- 入群审核默认拒绝未填写邮箱、邮箱格式错误和未找到网站用户的申请，并把具体原因写入 QQ 审核回复；邮箱用户查询兼容分页嵌套响应并扩大查询页大小。
- 账号命令上下文错误统一返回 `账号状态：context_invalid`；用量接口只忽略可选资料的临时失败，绑定失效会直接反馈对应状态。
- 余额预警查询区分启用、关闭、非 QQ、未授权、绑定失效、限流和响应异常等状态，推送提醒标记为 `triggered`。

## 1.4.2

- 适配最新 Sub2API 机器人接口的 `status`、`message_key`、`already_checked_in`、Token 门槛和错误 `metadata.status`，签到会分别返回成功、重复签到、功能未开启、Token 不足、账号停用和服务异常。
- 入群审核对未填写邮箱、邮箱格式错误和网站中不存在的邮箱分别拒绝，并把具体原因写入 QQ 审核回复；管理员接口或网络异常时保留申请等待重试。
- 绑定码无效、绑定数量达到上限、账号停用和绑定服务不可用等网站状态改为返回对应的中文原因。

## 1.4.1

- 适配 MaiBot SnowLuma 的 `adapter.napcat.group.get_group_system_msg` 和 `set_group_add_request` API；入群审核优先复用适配器已连接会话，`onebot_api_base` 为空时也能轮询并处理申请。

## 1.3.2

- 绑定码撤回优先调用 MaiBot 宿主的 `recall_message` 工具，兼容已启用 SnowLuma 撤回工具的适配器。
- 修复 `/我的用量` 一直提示“查询网站账号用量失败，请稍后重试。”的问题：格式化函数误用了未定义的全局 `_format_money`，取到数据后仍抛 `NameError`，现改为调用实例方法。
- 修复 `/我的用量`、`/Key用量` 失败时只提示“请稍后重试”的问题：按 HTTP 状态码和站点错误码给出具体原因，并把完整异常写入日志。
- `/我的用量` 不再把资料接口当作必需请求，避免两个请求同时命中网站限流导致整条命令失败；网站未返回余额时不再显示误导性的“-”，并补充 RPM、TPM 和平均耗时。
- 新增 `/绑定诊断`，逐项检查 `/bot/profile`、仪表盘用量和周期用量接口的状态与耗时，便于用户自查。
- 绑定码撤回改为真正执行：先探测宿主适配器对象，再按配置调用 OneBot HTTP `delete_msg`；未配置时明确提示无法撤回并建议手动撤回，不再承诺“尽力自动撤回”。
